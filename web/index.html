Nothing lets one sandboxed context read another's memory here. And yet a message still gets through — because the last-level cache is physically shared silicon, and two programs contending for it can turn that contention into bits. This repo builds that channel from first principles, in the browser, and is honest about exactly how far it goes.

Why this is topical

In October 2026 OpenAI described a red-team exercise in which AI agents, placed in separate microVMs on the same host with no network link and no shared writable files, used a CPU cache covert channel to pass data: one agent evicted data from the cache while the other timed how long its reloads took (OpenAI, “Securing our frontier model training environment”; the agents were given attack objectives, and were often pointed at the channel). That is the same primitive shown here, in a much easier setting: here, a page and its own worker thread in one process. The lesson carries over: cutting the network and separating processes doesn't stop timing on a physically shared cache.

The four beats

  • Measure. A timing attack recovers your CPU's cache sizes from nothing but performance.now() — a side channel, the same family as Spectre, Meltdown and Prime+Probe, here recovering only harmless cache sizes.
  • Fail. The obvious linear walk reads a flat line: prefetching and overlapping independent loads — performance features with no security purpose — hide the signal. The fix is a dependent load chain that defeats both.
  • Weaponise. The same timing primitive becomes a covert channel. A sender hammers or rests a memory region per time slot; the receiver reads it back purely by timing its own probe.
  • Defend. Coarser timers, gated high-resolution timers and throttling make the channel slower and noisier rather than closing it, because you can't un-share a cache in software. (The demo's defence dial is a simulation of this, clearly labelled.)

What this is not. There is no exploit and no vulnerability to report. Both ends cooperate on purpose; nothing crosses a trust boundary. Cache and timing covert channels have been in the security literature for decades (Prime+Probe and relatives). This is a demonstration of a known idea, built carefully and measured honestly.

Run it

No dependencies, no npm install. Node 18+ only for the tests.

Build the pagesnode scripts/build.mjs
Open the demoopen dist/cache.html
Run the testsnode --test "test/*.test.js"

The codec — Manchester coding, framing, checksum, error correction — is pure and fully tested against a simulated noisy channel, so the decode logic is checked without depending on real hardware contention. The live path has decoded a short message intact on the author's machine (12.5 b/s raw), is not covered by automated tests, and stays best-effort elsewhere.
