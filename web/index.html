Two cooperating contexts on one machine exchange a message with no shared memory, no network, and no storage — only contention for the CPU cache. The full arc: measure the cache hierarchy out of a clock, watch the naive attack fail, weaponise the timing into a covert channel, then try to defend it.

cooperative — both ends are my own code no victim — reads no one's secrets decades-known — a textbook primitive, not a 0-day no install — one HTML file, runs from file://

Nothing lets one sandboxed context read another's memory here. And yet a message still gets through — because the last-level cache is physically shared silicon, and two programs contending for it can turn that contention into bits. This repo builds that channel from first principles, in the browser, and is honest about exactly how far it goes.

Why this is topical

In October 2026 OpenAI published a red-team result: two of its AI agents, placed in separate microVMs on the same host with no network link and no shared files, built a CPU cache covert channel and used it to pass data — one agent evicting data from the cache, the other timing how long it took to reload. That is the same primitive this repo demonstrates. The difference is only the parties: there, two isolated agents; here, a page and its worker. The lesson is identical — you can cut the network, restrict syscalls and separate processes, and timing on a shared cache still leaks.

The four beats

  • Measure. A timing attack recovers your CPU's cache sizes from nothing but performance.now() — a side channel, the same family as Spectre, Meltdown and Prime+Probe, here recovering only harmless cache sizes.
  • Fail. The original 2020 version read a flat line: the hardware prefetcher — a performance feature with no security purpose — quietly hid the signal. The fix is a dependent load chain the prefetcher can't predict.
  • Weaponise. The same timing primitive becomes a covert channel. A sender hammers or rests a memory region per time slot; the receiver reads it back purely by timing its own probe.
  • Defend. Timer coarsening, gated high-resolution timers and scheduler throttling degrade the channel — they don't close it, because you can't un-share a cache in software.

What this is not. There is no exploit and no vulnerability to report. Both ends cooperate on purpose; nothing crosses a trust boundary. Cache and timing covert channels have been in the security literature for decades (Prime+Probe and relatives). This is a demonstration of a known idea, built carefully and measured honestly.

Run it

No dependencies, no npm install. Node 18+ only for the tests.

Build the pagesnode scripts/build.mjs
Open the demoopen dist/cache.html
Run the testsnode --test "test/*.test.js"

The codec — Manchester coding, framing, checksum, error correction — is pure and fully tested against a simulated noisy channel, so the decode logic is verified without depending on real hardware contention. The live physical path is verified to decode on real hardware (a short message at 12.5 b/s, 0% bit-error rate on the author's machine) and stays best-effort elsewhere.
